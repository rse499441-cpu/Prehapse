# 地下城探索 Bot

一个运行在 Discord 中的轻量 Roguelike 地下城游戏原型。

## 当前玩法

- 地下城共 100 层，每层需要完成随机步数的探索。
- 每个十层区间的第 5～8 层有概率出现小 Boss；第 10、20、30……100 层
  固定出现各自专属的大 Boss，其余楼层完成探索后直接进入下一层。
- 探索途中可能遇到分区怪物、旅行商人、宝箱、宝箱怪、多种陷阱、
  宁静泉水、受伤精灵、神秘石像、藏宝图、受困妖兽、地下许愿井或空房间。
- 体力用于承受伤害，魔力用于技能，精力用于探索和开启宝箱。
- 魔法分为星火弹、月辉矢、奥术流星三档，威力和消耗逐档提升。
- 死亡后等级、经验和层数重置；普通道具随机保留最多 2 个，金币减半；
  装备和魔法水晶保留。
- 每次击败第 100 层最终 Boss 后都会晋升通关身份组：依次获得
  `❄️ 一星冒险者`、`❄️ 二星冒险者`、`❄️ 三星冒险者`、`❄️ 四星冒险者`；
  第五次通关晋升为 `❄️ 初级冒险者`，并返回冒险者酒馆。
- 已解锁的通关称号颜色不会丢失，可随时使用 `/冒险者称号` 自选当前展示称号。
- Bot 上线时会读取既有存档，为已经通关的老玩家自动补发当前最高称号。
- 首次进入地下城会自动获得后台身份组 `🗺️ 地下城冒险者`；旧存档玩家会在
  Bot 上线时自动补发，用于接收地下城专属公告。
- 每次百层通关还会永久获得攻击 +5、防御 +3；加成独立于装备，换装不会丢失。
- 每周挑战按北京时间记录玩家当周到达的最高层数，每周六自动更新 TOP1～TOP15。
- 每日问卦与酒馆幸运联动：同一用户当天问卦总运达到 70/80/90 分时，
  受伤精灵与藏宝图的水晶概率分别增长 20%/40%/60%；北京时间次日自动失效。
- 玩家面板使用 Discord 横向字段展示体力、魔力与精力。

## 启动

1. 安装 Python 3.11 或更高版本。
2. 安装依赖：`pip install -r requirements.txt`
3. 将 `.env.example` 复制为 `.env`，填写 `DISCORD_TOKEN`。
4. 运行：`python bot.py`
5. 在 Discord 中输入 `/地下城`。

服务器管理员还可以使用 `/地下城测试`，从下拉菜单中指定普通怪物、宝箱、
伪装中的宝箱怪、泉水、旅行商人、陷阱、小 Boss 或大 Boss，方便逐项检查面板。

如果填写了 `TEST_GUILD_ID`，指令会优先同步到该测试服务器，通常几秒内可见；不填写则注册为全局指令。填写 `DUNGEON_CHANNEL_ID` 后，地下城指令只能在指定文字频道使用。

填写 `DUNGEON_RANKING_CHANNEL_ID` 后，每周六会在该频道自动更新挑战层数排行；
留空时 Bot 会自动创建只读的 `🏆・每周挑战排行` 专用频道。管理员也可以在目标频道
运行 `/设置挑战排行频道` 进行更换。随时使用 `/挑战排行` 可查看本周榜单。

`/地下城测试` 的下拉选项包含“立即死亡结算”“百层通关庆祝”和
“全部清零并从头开始”，用于管理员检查死亡面板、通关庆祝面板、身份组奖励，
以及删除自己的测试存档与本周榜单记录。

百层身份组优先使用冰魄蓝到霜雪蓝白的渐变样式。服务器需要启用 Discord
Enhanced Role Styles；未启用时会自动使用冰魄蓝纯色。Bot 需要“管理身份组”权限，
且 Bot 自身身份组必须位于奖励身份组上方。

## 在 GitHub Codespaces 运行

1. 在仓库页面点击 **Code → Codespaces → Create codespace on main**。
2. 在 Codespaces 终端执行：

   ```bash
   cp .env.example .env
   nano .env
   ```

3. 在 `.env` 中填写 Bot Token、测试服务器 ID 和地下城频道 ID，保存后执行：

   ```bash
   pip install -r requirements.txt
   python bot.py
   ```

4. 看到 `已登录：机器人名称` 后，前往指定 Discord 频道输入 `/地下城`。

`.env` 已被 Git 忽略，不要将 Token 提交到仓库。Codespace 终端需要保持运行；停止 Codespace 后 Bot 会离线。

## 当前版本说明

旅行商人每次相遇会随机携带四件商品，初始货位与付费整店刷新按药剂 60%、护符 25%、
装备 15% 生成。药剂或护符售罄后也按 60%／25%／15% 随机补货；武器或护具售罄后
只会补药剂 70% 或护符 30%，不会连续补装备。装备库存 1，药剂库存 4，
买空后才补货，也可支付高额金币刷新全部四格。每次相遇最多刷新 5 次，售罄补货
和付费刷新共用额度。护符提供少量永久属性，价格随楼层提高。

金币商店、旅行商人与水晶兑换取得的装备统一进入去重装备库，玩家可分页下拉选择
武器和护具；同名装备只显示一次。

所有饮药动作消耗 2 精力。普通精力药水实际净恢复最多 28，强效精力药水净恢复
最多 58；强效精力药水从 20 层后进入事件奖励，并在 30 层后的商人处更常受到推荐。

通关 100 层后进入下一星远征：等级与经验重置为 1 级，装备库、货币、道具和永久
属性保留。每颗星使怪物生命 +50%、攻击 +30%、经验 +15%，金币只小幅增加 8%。
普通物理攻击无论防御多高都至少保留 15% 原始伤害；敌人拥有分级暴击率，高层怪物
和大小 Boss 会先咏唱再释放魔法。十个区域 Boss 分别拥有腐蚀、护盾、汲取、封印、
连击、冻结、治疗等不同能力。

旅行商人与水晶秘藏的护符现在覆盖攻击、防御、敏捷和幸运四种小额永久加成；
攻击护符的点数低于武器成长，作为稀有的长期积累奖励。

金币商店扩充为每日 4 件武器、4 件护具、4 件道具，并使用更大的跨日随机池。
小 Boss 仅有 12%、大 Boss 仅有 25% 概率掉落装备，且掉落稀有度受楼层限制；
81 层后即使成功掉装，传说也只有 3% 二次概率，取得后自动进入去重装备库。
水晶秘藏同步扩充为 134 件装备与护符。

最新调整：所有用户可见数值最多显示两位小数，普通攻击与生命结算也按两位精度保存；
旅行商人攻击、防御、敏捷、幸运四类护符分别统计各自累计数量，并分别代入六档边际倍率
累计公式；超过 100 枚的部分按 10%继续增长。旧固定 +1 属性会从最早线上备份恢复真实
基数、从永久属性中剥离，再按新公式写回。所有位于冒险者酒馆的玩家
均可使用储值商人；旅行商人的 5 次共享刷新额度耗尽后，空库存不会自动补满。
50—100 层金币旧公式占比由 1/3 线性降至 1/5。

精力不足且没有精力药水时可呼叫紧急救援：选择鼹鼠车夫会按死亡方式结算，
金币减半、普通道具随机只保留两件，并以满状态 1 级返回酒馆；也可放弃全部
等级与经验，向女神祈祷后以满状态 1 级回到地下城第 1 层继续冒险。

酒馆水晶兑换每次消耗 3 枚魔法水晶，必定获得优良以上的武器、护具或永久护符。
概率为优良 45%、稀有 35%、黄金 17%、传说 3%，可一次砸 1、5 或 10 次。
冒险途中也能从酒馆入口点击水晶兑换，不会重置当前楼层、战斗或探索进度；
开出的装备进入去重装备库，护符立即生效。
装备抽取会在下一阶段接入。项目使用独立 SQLite 数据库，不会读取或修改现有签到 Bot。

金币商城只在冒险者酒馆开放，冒险途中无法进入。商城库存按北京时间每日刷新，
每天提供武器、护具和道具；购买装备后会立即换装，攻击、防御、敏捷和幸运数值会真正影响战斗、
陷阱伤害与宝箱收益。酒馆的今日冒险委托也会在每天刷新。

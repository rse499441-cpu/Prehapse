# 私有 Discord 游戏合集

本仓库用于两款 Discord 游戏的私密开发协作，请勿公开仓库或转发源代码、配置及素材。

## 01-dungeon-explorer

地下城探索 Bot 的当前源代码、测试、运行素材和部署示例。具体玩法、安装和启动方式见该目录内的 `README.md`。

## 02-yan-qingchuan-casino

晏青川赌场 Bot 的当前源代码、运行素材和部署示例。赌场与地下城共用金币钱包，具体配置方式见该目录内的 `README.md`。

## 安全约定

- 不提交 `.env`、Discord Bot Token 或其他密钥。
- 不提交真实玩家数据库、存档、日志、服务器备份或部署压缩包。
- 新配置请从各项目的 `.env.example` 复制到本地 `.env`。
- 仓库必须保持为 GitHub **Private**，只邀请明确参与开发的协作者。
